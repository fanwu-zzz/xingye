## 2. 数据和验收口径

- Room 版本 **8**，提供 5→6、6→7、7→8 增量迁移；不清空旧日历、会话和专注。
- 周/月统计区分计划时长、已完成安排的计划时长与实际专注。实际专注只计有效时间片，排除暂停与休息。
- 新任务的完成/撤销完成维护真实完成时间；旧已完成任务时间保持未知。原统计页“连续完成”仍按有已完成任务的安排日期计算；复盘中的实际完成量另按完成时间计算。
- 目标历史周只读，本周或未来调整不改变旧周分母。关联计划仅使用专注开始时的归属快照，缺失不推测。
- 备份排除密钥和系统权限，手动备份不是云同步。导入上限 10 MB；失败整体回滚。相同专注身份时长不同会阻止恢复。
- 重复课程保留单次调课/停课例外；已有未关联 CLASS 不自动猜测规则。批量更新前呈现重复与冲突，取消不写入。
- 本地复盘不联网；完整摘要、目的地和数据范围经明确确认后发送 DeepSeek。AI 建议先成为草稿，应用前再次确认；任何日程冲突均阻止整次应用。

## 3. 验证记录

编译/单元测试：` .\gradlew.bat assembleDebug testDebugUnitTest --console=plain`。

设备回归：` .\gradlew.bat connectedFocusTestAndroidTest --console=plain`。仅安装/卸载独立应用 `com.fanwu.studyplanner.f01test`；日常应用不清空或卸载。测试前已只读备份日常数据库及 WAL 至 Git 忽略的 `app/build/device-backups/F02-F06-before/`。

覆盖目标版本、跨周专注、单双周/节次、预览取消与过期、单次调课/停课、重复/冲突、备份关联/去重/覆盖/回滚、数据库迁移、复盘真实数据与建议保护。AI 请求使用伪造服务验证，不发送用户数据作测试。

最终结果：`assembleDebug` 成功，**45 项 JVM 单元测试、40 项设备测试全部通过**（Android 9 / API 28 联想模拟器）。其中包括 6→8、7→8 的实际 Room 迁移校验。设备测试结束后独立测试包由驱动移除；日常应用的安装时间、数据库 SHA-256 与测试前一致。

实际界面检查：普通手机上的目标页/编辑弹窗、学期表单及重叠课程周网格；360dp / 1.3 倍字体下的统计和复盘正文；640dp 宽屏下的复盘草稿、发送确认与取消、备份页面、恢复策略及二次确认。通过系统文件选择器完成了临时测试数据的 JSON 导出→选择导入→重复预览→合并恢复，日程新增 0、覆盖 0、跳过 6，未制造重复。测试文件已清理，显示密度和字体恢复默认。未调用真实 DeepSeek 服务，未完成的环境兼容项见下一节。
