# F02 / F04 / F05 / F06 实现说明

更新：2026-10-26。F01、F03 继续使用各自说明；本文件记录其余四项正式功能。

## 数据结构与迁移

Room 版本 7→8：仅增加 `planner_documents` 和日历可空字段 `completedAt`、`subject`、`recurringCourseId`、`originalOccurrenceDate`，不删除旧表，不使用破坏性迁移。旧已完成任务的完成时间保持未知，不按迁移时间填充。目标历史、学期、课程规则和复盘草稿使用带类型的 JSON 聚合存入 Room；时间片与日程继续采用关系表。备份来源与导入映射属于内部记录，不导出为业务文档。

任务完成操作记录真实时间，重复完成不改时间，撤销完成清空时间。专注开始时快照计划和科目，不随以后改名、删除任务而推测历史归属。旧专注 JSON 可读取，新可选字段默认空。

## F02：每周目标

- 入口：我的 / 统计 → 学习目标。可新增、编辑、暂停、归档和恢复；设置名称、每周小时数、可选截止日期与计划关联。
- 每周目标为 1 分钟至 168 小时，支持小数小时并换算到分钟。名称、日期和生效周经过校验。
- 修订包含稳定 `goalId`、本次修订 ID、生效周、创建时间。相同目标同一生效周的配置替换；之后周的配置追加。历史周只读，编辑只从本周或选定的未来周生效，过去周分母不改变。
- 分子只统计 F01 已结算时间片，在各片段记录时区按本地日期拆分；暂停、休息和未结算的实时尾段不计。关联计划只使用专注开始时保存的归属，缺失时不推测。全量目标允许计入自由专注。
- 暂停、归档保留目标及真实投入，方便回看。截止日期为目标的提示信息，不自动删除记录。多个目标可共享同一段专注，不能把各目标投入相加当作总投入。

## F04：手动备份与恢复

- 入口：我的 → 数据与备份。使用系统 `CreateDocument` / `OpenDocument`，不申请全盘存储权限。
- JSON 格式 v1：`schemaVersion`、导出时间、应用版本、稳定来源 ID、日历、对话/消息、专注轮次/时间片、目标修订、学期/课程规则、复盘草稿与提醒设置。
- 明确排除 API Key 设置、Keystore 和编译期密钥；应用不读取这些内容来制作备份。对话和备注本身仍属于用户数据，文件应保存在可信位置。此功能不是云同步。
- 文件最大 10 MB，业务记录总数有上限。导入读取时限制容量；拒绝未知版本、重复主键、错误日期/时间、非法状态、损坏的关联及不一致专注累计时长。未知结构不自动猜测迁移。
- 先预览数量、已识别重复、日程/配置冲突，再选择「合并、冲突保留本机」或「合并、匹配项用备份覆盖」，最后二次确认。不会清空整库。
- 日程优先按来源映射匹配；同一设备来源可按原 ID；否则以标题、日期、开始时间、类型匹配。相同内容去重，冲突按用户策略处理。对话保持消息归属，消息按来源凭据及内容/时间去重。
- 目标同一 `goalId` 和生效周视为匹配配置，即使修订 ID 不同也遵循跳过/覆盖策略。学期、课程、复盘按文档 ID 匹配。
- 覆盖策略更新匹配日程、配置、对话名称及提醒设置；消息、专注只追加去重，不删除历史。专注以 UUID 为不可变身份；相同 UUID 的累计时长不同会阻止恢复，不能双计或静默覆盖。
- 恢复重新映射日程 ID，保持专注关联；已删除任务的历史轮次可独立备份，保留标题但不恢复失效 ID。未完成专注恢复成提前结束，保留已结算时长，不自动开启前台计时。恢复前必须结束本机当前轮次。
- 预览时保存本地数据快照，确认前若有变化要求重新预览。全部导入在一个 Room 事务中完成，失败回滚。事务后提醒重新协调，统计通过数据库 Flow 更新。

## F05：学期与重复课程

- 入口：本周课表 → 学期与节次设置。可管理多个学期，设第一周周一、1—30 周和作息表。
- 开学日期使用日期选择器，明确换算到所在周一。作息每行 `节次,开始,结束`，支持增删编辑、按编号排序，拒绝重复编号和时间重叠。可保留导入时只有总时间的合并节次，例如 `1-2,08:00,09:40`；没有单节时间时不猜测拆分时间。
- 重复课程保存星期、原始周次、节次、教室、学期 ID、生效范围及例外日期，支持单双周、跳周和连堂。
- 整门编辑通过同一规则重排；指定日期及以后拆分前后两段规则。单次编辑/删除时保存原日期与教学周例外，整门修改星期或移动开学日期后仍不复活停课、不覆盖调课。删除整门课程前二次确认并预览。
- 所有批量操作先展示将替换/生成的数量、完全重复及时间冲突。冲突允许用户明确确认后保留，并在周网格并列显示；手动任务、考试、未关联课程不被替换。预览取消不写入设置和事件；数据变化要求重建预览。
- Excel 识别结果保留原始规则，确认后同时保存学期、重复课程和具体事件。重复导入更新关联规则，保留同规则的单次例外。只有合并节次总时间时要求补齐作息，不能凭空计算子节次时间。
- 升级前已有 CLASS 事件完整保留，仍可单独编辑/删除；不会根据课程标题自动把旧事件猜测成系列。与这些旧事件完全相同的新事件会在预览中去重跳过。
- 本周课表新增可横向滚动的真实时间网格；同一天重叠课程分列，保留完整的按天列表供阅读。课程仍不显示来源对话名。

## F06：本地周报与 AI 建议草稿

- 入口：统计 → 每周学习复盘。可切换历史周；本地周报离线生成，包含计划分钟、实际专注、安排任务当前完成情况、未完成逾期、已知延期完成、真实完成日期计数、科目实际投入及缺失值说明。
- 任务安排量只统计学习任务，课程与考试不混入；状态是当前快照，不伪装成历史结算快照。旧已完成任务没有时间戳时不推测日期。缺少科目的时间片归为未标注/自由专注，不伪造排名或提升率。
- 请求 AI 前冻结本次摘要，在对话框完整展示摘要、范围、目的地 `https://api.deepseek.com/chat/completions` 和字段说明。只有点击「同意发送此摘要至 DeepSeek」才调用接口。打开页面、关闭对话框和取消均不发送。
- 发送摘要包括科目标签和汇总数字，不附带历史对话、备份或备注。认证沿用现有 API Key 存储，仅发往固定 DeepSeek 接口；本地测试使用伪造的 API 实现，不调用用户服务。
- 显示真实生成状态，支持取消和重新确认重试；退出页面取消未完成请求。失败保留本地摘要。
- AI 返回文字建议和可空的下周学习任务，先校验日期、类型与时间，再持久化草稿。可以编辑或移除任务。应用仍要预览并确认；与任何已有日程或草稿内部冲突时整体阻止，不覆盖课程、考试或任务。
- 已应用状态与新增日程在同一事务中保存，重复应用不会重复写入。文字建议无日程时只展示文字。
