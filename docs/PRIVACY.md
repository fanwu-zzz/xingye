# 数据与隐私说明

- 日历、课表、任务、对话、专注和复盘记录主要保存在设备的应用数据库。Android 系统的自动备份或设备迁移可能按系统配置保存和迁移这些数据；应用的手动 JSON 备份只写入用户选择的位置。
- DeepSeek API Key 保存在由 Android Keystore 保护的加密偏好文件中。该文件不参与 Android 自动备份和设备迁移，也不写入应用的手动 JSON 备份；换机时需要重新配置。
- 使用 AI 对话、生成计划或确认发送 AI 复盘时，相关输入和用于服务鉴权的 API Key 会发送到 DeepSeek API。具体处理遵循服务商政策，使用者需自行确认费用和适用条款。
- Excel 课表导入使用用户选择的文件；手动备份和恢复使用 Android 系统文件选择器。专注和提醒会使用系统通知、前台服务及闹钟权限。
- 项目没有接入广告或分析 SDK。网络客户端只配置 DeepSeek API；Android 系统服务和用户选择的文件服务可能分别处理其管理的数据。

发现隐私或安全问题请阅读 [安全反馈说明](../SECURITY.md)。
