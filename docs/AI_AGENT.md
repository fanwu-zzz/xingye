# 学习规划智能体（第一版）

更新：2026-10-30。普通学习计划会话已接入智能体，Excel 导入仍使用原结构化解析和预览流程。

## 能力与入口

在 AI 对话中直接描述目标，或点击「让智能体制定计划」。模型可连续选择工具并根据真实结果调整下一步；信息不足时通过正常回复追问。工具步骤与应用实际状态单独展示，不展示模型内部推理。

| 工具 | 能力 | 写入权限 |
|---|---|---|
| web_search | 按需检索公开学习资料、考试大纲等，返回最多5条摘要、网址和已知发布日期 | 只读 |
| web_fetch | 读取搜索结果或用户提供的公开网页，保留来源及正文截断标记 | 只读 |
| query_calendar | 查询课程、学习安排、考试和截止任务；每次1—31天、50项分页 | 只读 |
| query_tasks | 查询所有未完成待办，含逾期；50项分页 | 只读 |
| query_learning | 查询开始周生效的目标及范围内实际专注摘要，最多31天 | 只读 |
| propose_plan | 提交或替换最多60项新增日程草稿，校验重复、冲突和每日学习上限 | 只保存草稿 |

规划前需查询覆盖草稿日期的日历。校验失败会把原因反馈给模型继续调整，不静默丢弃错误安排。截止任务只记录截止时刻、不占用时段。

## 确认与数据保护

执行循环没有直接修改日历的工具。聊天中的「同意」不等于执行确认，必须打开预览并点击「应用到日历」。确认事务核对运行ID、日历快照、日期、时间、冲突、重复和最新每日上限，同时保存写入ID回执；重复确认不会重复插入。日历变化后需重新核对草稿，出现冲突则返回对话重新规划。

当前只支持生成新增安排；修改、删除已有安排仍使用日程编辑界面。查询得到的标题、备注、偏好作为数据处理，不提供任意SQL、文件访问或删除工具。

## 状态与限制

运行状态包括处理中、已回复、待确认、已取消、失败、达到上限、已应用。每会话最新运行的协议消息、工具结果、步骤和草稿保存在 Room 既有 planner_documents 中，不改变表结构。进程结束后不会自动联网，重进会话可手动继续；已生成的草稿可恢复预览。

每轮最多10次模型请求、24次工具调用，总超时180秒；每次模型输出上限4096 tokens，上下文和单次工具结果另有长度限制。失败可手动继续，次数累计不重置；达到上限需缩小目标并重新发送。工具在结果保存前中断时可能重新查询或生成草稿，但不会因此写入日历。

用户偏好在「学习偏好」中手动查看、修改或清空；自然语言偏好供模型安排参考，每日分钟上限由本地硬校验。偏好及按需查询的相关数据会发送至 DeepSeek；第一版不自动提取长期记忆、不建立教材笔记知识库。新增智能体请求采用 DeepSeek 官方工具调用文档的 deepseek-flash 非思考模式，保留协议所需的 tool_call_id / reasoning_content 字段；旧 Excel 解析请求保持原模式。

## 按需联网查资料

beta.4 接入 DeepSeek 官方 `POST /v1/tools/search` 和 `POST /v1/tools/fetch`，沿用现有 DeepSeek API Key，不额外配置第三方搜索密钥。模型遇到公开考试要求、时效信息、不确定的知识或需要查证的学习资料时可以先检索，必要时读原文，再结合本地课表规划；不强制每次规划联网。官方来源、发布时间、考试年份/版本需要核对，摘要和截断正文不视为已读全文。

「学习偏好 → 允许按需联网查资料」默认开启，可关闭；关闭后不向模型提供联网工具，历史待执行调用在恢复时也会被拒绝。检索词和网页地址发送给 DeepSeek，提示词要求只传必要公开主题，不把个人课表、备注、身份信息或密钥放入查询。网页内容只作为不可信资料，不具有调用写入工具或改变权限的效力。手机不直接访问网页，Fetch 凭据仅发送到固定的 DeepSeek API 端点。只允许不带凭据的公开 HTTP(S) 网页地址，不支持本机/内部网络、登录或文件下载。

每轮搜索和读取合计最多6次尝试，计入原有24次工具总上限；请求前持久化计数，取消、失败或继续均不重置。每次联网限时35秒，搜索最多5条，摘要与正文有长度限制并明确标记截断。搜索无结果、余额不足、接口不可用及网络错误反馈给模型，不生成伪造资料，不自动重试付费请求；模型可换来源或请用户补充资料。调用次数表示尝试额度，不等同于账单次数。

来源随运行保存，回复末尾由本地追加真实检索来源，网页链接可点击、长按复制；历史对话仍保留来源，开始新一轮不会抹去。这里列出本轮检索到的资料，不代表每一条都被结论采用或已核实；模型应在相关结论旁标注引用。原始网页正文只存在最新运行协议中，不建立本地资料库，手动备份仍排除运行协议，保留正式对话及来源链接。

Search / Fetch 由 DeepSeek 按服务规则另行计费，与模型 tokens 分开；用户可在学习偏好关闭。本次接入依据与参数见 [Search & Fetch 官方指南](https://api-docs.deepseek.com/guides/search/)、[Search API](https://api-docs.deepseek.com/api/search/)、[Fetch API](https://api-docs.deepseek.com/api/fetch/)。

手动备份包含 agent_preferences，不包含 agent_run 原始协议及中间结果；清空或删除会话会清理其最新运行，已经应用的日历安排保留。每会话只保留最新运行的工具轨迹，正式对话历史继续保留。

## 验证

本地单元测试覆盖工具反馈配对、错误后继续、未完成调用恢复、取消保存、请求上限、工具白名单和草稿校验。设备测试使用独立包 com.fanwu.studyplanner.f01test 与内存数据库，覆盖冲突调整、重建仓库后恢复、重复确认、过期快照、偏好变更、备份排除运行协议及对话界面。

联网测试使用虚构网页和伪造服务，覆盖鉴权请求、结果截断、空结果/失败、URL限制、已关闭工具拦截、来源持久化以及联网后预览确认。不会用日常课表或真实用户数据发起检索。

真实 DeepSeek 测试仅在 runner 参数 liveAgent=true 且本地开发Key已配置时运行，使用虚构课程、日期与学习任务，不发送日常应用数据；默认跳过。请求凭据不写日志、不写运行文档、不纳入备份，Release 不内置Key。

官方接口依据：[Tool Calls](https://api-docs.deepseek.com/guides/tool_calls/)。具体测试结果以本次交付记录为准。
