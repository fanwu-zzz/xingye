# UI 重构说明

日期：2026-10-25。

## 视觉系统

遵循 .trae/rules/ui_style.md：纸白页面、直角、纯黑结构线、无模糊硬阴影、亮黄选中态、粉色主操作。学习任务用荧光绿、课程用青色、考试用橙色。颜色集中在 Color.kt，字号与字重集中在 Type.kt，应用固定浅色。

Material 的 Shapes 使用 0dp 圆角（其类型要求 CornerBasedShape），业务组件使用直角；不使用默认浮起阴影。共享按钮保持点击命中区固定，触摸按下移至静止阴影位置，悬停时抬起并增大阴影。

## 页面结构

- 底部三个一级入口：日历、统计、我的。
- 日历：日期条 / 月历 → 当日概览 → AI 计划 → 全部任务 / 本周课表 / 专注 → 当日日程。
- 任务：搜索 + 状态 + 类型筛选 → 按日期组织的真实任务 → 详情 / 编辑 / 完成。
- AI：会话列表 → 学习计划或课表导入会话 → 计划预览 → 确认应用。
- 统计：周/月 → 计划时长与完成率 → 每日计划图表 → 待办计划组 → 目标与复盘入口。
- 我的：学习工具 → AI 设置 / 提醒 / 数据 → 版本说明。
- 课表：周切换 → 手动课程 / Excel 导入 / 学期设置 → 时间网格与重叠课程分列 → 按天列表。
- F01—F06 均已接入真实数据与持久化：目标历史及实际进度、系统文件备份恢复、学期与重复课程、离线周报和明确确认后的 AI 建议草稿。功能预览页已经移除；课程与恢复等变更仍先预览再确认。
